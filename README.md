# THE ROAD TO EPIK HIGH 🎮

**复古像素风的 Epik High 音乐档案馆与演唱会倒数助手**。这是一个非官方粉丝项目。

## 部署到 GitHub Pages（无需编程）

1. 在 GitHub 上创建一个 **Public** 仓库，例如 `epik-high`（也可以是其他名称）。
2. 解压发布 ZIP，将其中的 `index.html`、`assets/`、`preview/`、`.nojekyll` 和这些 Markdown 文件**直接上传到仓库根目录**。不要把外层文件夹再嵌套进去。
3. 打开仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **Deploy from a branch**，**Branch** 选择 `main`，目录选 `/(root)`，点击 Save。
4. 部署完成后打开 `https://你的用户名.github.io/仓库名/`。如果仓库恰好叫 `你的用户名.github.io`，地址则是 `https://你的用户名.github.io/`。
5. 用手机浏览器检查首页、档案搜索、74 天倒数任务、歌单和行程助手；再把正式网址分享给粉丝。

> **请勿直接上传 ZIP 文件当作网站。** 必须先解压、把 `index.html` 放在仓库根目录；Pages 不会自动解压你的 ZIP。

## 本版本功能

- 演唱会倒数与 2027 年 1 月 22–24 日三场选择
- 74 天音乐任务、唱片收藏、打卡、每日探索和记忆格
- Epik High 歌曲、专辑、视频、访谈等档案检索及来源状态筛选
- 历史演唱会歌单、个人预习与行程准备
- 文本 / CSV / JSON 资料导入、审核与导出
- 手机端复古像素主题

## 重要说明

- **本站不需要服务器**：HTML 内包含主要 CSS、JavaScript 和初始数据；也不需要单独配置 npm、Node.js 或数据库。
- **个人数据仅保存在当前浏览器**：收藏、笔记、已完成任务和手动导入内容使用 `localStorage`。不同访问者或不同设备不会自动同步，清理浏览器数据可能使其丢失。建议用档案导出功能定期备份自行添加的记录。
- **旧版数据不会自动迁移到新网址**：如果之前用本地 HTML 或其他域名使用网站，浏览器存储会因域名不同而隔离；请先在旧版导出资料，再在新站导入。
- **内容核验**：部分旧版候选条目仍标记为“待核验”。公开发布前建议再次检查历史事实、成员照片授权、视频和音乐外链，不要把候选记录当成已证实信息。
- **外部资源**：部分人物照片与音乐链接需要联网访问第三方平台，可能受所在地区、平台政策、隐私插件影响。
- **信息抓取限制**：浏览器内尝试读取外部公开网页可能因跨域或第三方服务故障而失败。可以改用粘贴内容、CSV 或 JSON 导入；没有自动的持续后台采集服务。
- **版权/声明**：这是粉丝制作的非官方网站，与艺人或所属公司无官方关联。音乐、图片、视频等权利归相应权利人；发布前应核实对第三方素材的使用权限。

## 维护更新

以后更新网页时，只需要用新版本覆盖仓库根目录的 `index.html` 并提交变更；GitHub Pages 会自动重新部署。保持仓库路径和站点网址不变，可帮助已有访客保留当前域名下的浏览器本地记录（前提是更新代码保留兼容的存储键）。

详细操作见 [DEPLOY_GUIDE.md](DEPLOY_GUIDE.md)。
